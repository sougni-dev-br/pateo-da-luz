## Fluxo do `runRealSync(year, month)`

Loop nas lojas `NOVENTA_NOVE` ativas com `externalId` real (não `PENDENTE-*`),
cada passo tolerante a falha (padrão `runStep` do iFood), `NoventaNoveSyncLog`
no fim. Período `(year, month)` → `start_date`/`end_date` em `YYYYMMDD` (um mês
≤ 31 dias, dentro do limite da 99; fim capado em hoje).

Por loja:

1. **`syncStoreBillDetails`** → `getBillDetails({appShopId, período})`
   - `orderType=1` (receita): **upsert** `NoventaNoveSale` por (loja, `orderId`)
     — reconcilia a comissão real por cima da estimativa do webhook.
   - `orderType 2/3/4` (refunds): não vira "venda"; entra como ajuste no
     agregado de taxas/líquido (settlementAmount já vem negativo).
   - Agrega comissão/taxas do período pro passo 4.
2. **`syncStoreSettlements`** → `getSettlements({appShopId, período})`
   - **upsert** `NoventaNoveSettlement` por (loja, `weekPaymentId`).
   - Espelha em `Receivable` via `upsertReceivableFromNoventaNoveSettlement`
     (idempotente, não sobrescreve baixa manual).
3. **`reflectSalesIntoRevenueEntries`** → agrega `NoventaNoveSale` por dia →
   `RevenueEntry` (`sourcePlatform: "NOVENTA_NOVE"`, id determinístico
   `nnfood-<storeId>-<YYYYMMDD>`). Só roda com `companyId` setado.
4. **`reflectFeesIntoMonthlyExpense`** → agrega comissão + taxas do mês →
   `NoventaNoveMonthlyExpense` (Contas a Pagar), `dueDate` dia 10 do mês
   seguinte, respeitando edição manual (`autoGenerated && status=OPEN`).

## Mapeamento de campos (valores em centavos → ÷100 no Decimal(14,2))

### Get Settlements → NoventaNoveSettlement + Receivable
| Model | Origem (getShopBillWeek) |
|---|---|
| `externalId` | `weekPaymentId` |
| `periodStart` / `periodEnd` | `settleStartDate` / `settleEndDate` (YYYYMMDD) |
| `netAmount` | `withdrawAmount` / 100 |
| `paidAt` | `withdrawDate` (ISO) |
| `status` | `"PAID"` (repasse já efetivado) |
| `grossAmount` / `totalFees` | **decisão A** (agregado do Bill Detail via `dayPaymentIDList`, ou = líquido / 0) |
| Receivable | `sourceType=NOVENTA_NOVE_SETTLEMENT`, `sourceRef=weekPaymentId`, `customerName="99 Food"`, `paymentMethod="NOVENTA_NOVE_REPASSE"` |

### Get Bill Data (orderType=1) → NoventaNoveSale
| Model | Origem (getShopBillDetail) |
|---|---|
| `externalOrderId` | `orderId` |
| `orderDate` | `businessDateTime` |
| `grossAmount` | `orderAmount` / 100 |
| `noventaNoveFeeAmount` | `commissionAmount` / 100 (**comissão real** — decisão B) |
| `deliveryFeeAmount` | `b2pDeliveryAmount` / 100 |
| `netAmount` | `settlementAmount` / 100 |
| `paymentMethod` | `paymentChannel` mapeado |
